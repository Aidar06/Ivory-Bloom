# Ivory Bloom

Отдельный mobile-first шаблон свадебного приглашения в жемчужно-кремовой стилистике с зафиксированным анимированным фоном и прокручиваемой светопрозрачной центральной панелью.

- ID берётся из первого сегмента URL: `/3` → `3`.
- Данные загружаются через `GET https://x8ki-letl-twmt.n7.xano.io/api:X8-e2j1w/priglosi/{id}`.
- RSVP сохраняется существующим способом: свежий `GET`, добавление гостя и `PATCH /priglosi/{id}/full`.
- Поддерживаются `ru`, `ky`, `kk`, карты, пустые необязательные поля, загрузка, ошибка и несуществующий ID.
- Фоновое видео без звука; при `prefers-reduced-motion` остаётся статичный постер.

Локальный запуск:

```powershell
node scripts/serve.mjs
```

Открыть: `http://127.0.0.1:4180/3`.
